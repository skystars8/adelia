# Changelog

All notable changes to Adelia will be documented here.

## 0.1.0 - Preview

- Initial generic release for hobby and educational communities.
- Rust/Axum write and moderation application with PostgreSQL.
- Static board, thread, catalog, archive, news, and landing pages.
- Responsive removable-frame layout and vanilla JavaScript interactions.
- Validated image uploads, thumbnails, random banners, themes, and secure tripcodes.
- Reports, approval queue, editing/image replacement, deletion, locks, stickies, board settings, and news.
- Optional shared posting passwords and per-board approval/locking.
- No application-level IP address collection.
- Windows, Linux, Docker, and Ubuntu VPS documentation.
- Clear ChatGPT/OpenAI authorship and AI-friendly contribution guidance.
